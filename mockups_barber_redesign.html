🚨 Problemas Identificados

1. Falta de jerarquía visual
Todo el contenido se ve igual (tamaño, peso, contraste). No está claro qué es importante.
2. Navegación confusa
Emojis como "⏰ Horario 💰 📷 📊 Stats" no son claros ni profesionales. Usuario no sabe si son clickeables.
3. Botones de acción demasiado pequeños
Círculos de 28x28px contra target size mínimo de 48x48px. Muy difícil de tocar en M9 (1080x1920).
4. Colores caóticos sin coherencia
Amarillo dorado para horas, otro para estado "Pendiente", verde para confirmadas. Sin lógica visual.
5. Spacing muy apretado
Items de cita no tienen separación clara. Se ven como una pared de texto.
6. Tipografía sin variación
Nombres de clientes no destacan. Sin diferencia visual entre títulos y detalles.
7. Sin feedback visual
No hay animations, hover states, o estados de selección. La app se siente muerta.

✅ Recomendaciones de Implementación

1. Crear theme.ts centralizado
Define colores, tipografía, spacing en un lugar. Exporta constants para toda la app.
export const COLORS = { primary: '#C9A84C', success: '#00dd00', pending: '#ffd700' }
2. Rediseñar componente AppointmentCard
- Aumentar padding (14px en lugar de 12px)
- Borde izquierdo dorado (4px) para jerarquía
- Hora grande (20px, bold) al inicio
- Estado en badge pequeño (11px, uppercase)
3. Botones GRANDES y accesibles
- Mínimo 48x48px (standard Android)
- Grid 2 columnas en lugar de circles
- Texto claro: "Confirmar" y "Rechazar" en lugar de ✓ y ✕
- Active/pressed states con animación
4. Tabs profesionales
Reemplazar emojis con texto + underline activo:
Agenda | Horario | Stats | Más
Con background pills para tab activo.
5. Mejorar tipografía y spacing
- Nombre cliente: 15px, bold (weight 600), color blanco
- Email: 12px, color #888
- Servicio: 12px, color #aaa con borde top sutil
- Separación clara entre items (12px gap)
6. Bottom navigation clara
4 tabs principales: Agenda | Horario | Stats | Perfil
Con iconos + labels pequeños, active tab con color dorado.
7. Animaciones y feedback
- Item presionado: translateY(-2px) + sombra dorada
- Botones activos: cambio de color + scale(0.98)
- Transiciones suaves (0.2s)
