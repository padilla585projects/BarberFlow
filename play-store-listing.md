# BarberFlow — Ficha de Google Play Store

## Nombre de la app
BarberFlow - Gestiona tu barbería

## Descripción breve (80 caracteres máx.)
Gestiona citas, barberos, inventario y ventas de tu barbería desde el móvil.

## Descripción completa (4000 caracteres máx.)
BarberFlow es la herramienta todo-en-uno para barberías modernas. Diseñada para dueños, barberos y clientes, esta app te permite gestionar tu negocio de forma profesional desde cualquier lugar.

**Para dueños de barbería:**
- Crea y gestiona tu barbería con horarios personalizables
- Administra tu equipo de barberos con sistema de invitaciones
- Controla citas, servicios y precios en tiempo real
- Gestiona inventario de productos con alertas de stock
- Punto de venta (TPV) integrado para cobrar servicios y productos
- Reportes financieros con exportación a Excel
- Sistema de promociones y códigos de descuento
- Galería de fotos para mostrar tu trabajo
- Sistema de fidelización con puntos para clientes
- Panel de valoraciones y reseñas

**Para barberos:**
- Agenda personal con todas tus citas del día
- Gestiona tu horario y disponibilidad
- Portfolio profesional para mostrar tu trabajo
- Estadísticas de rendimiento y ganancias
- Trabaja en múltiples barberías con una sola cuenta

**Para clientes:**
- Encuentra barberías cerca de ti
- Reserva citas en segundos eligiendo barbero, servicio y horario
- Historial de citas y valoraciones
- Sistema de puntos de fidelización
- Notificaciones de recordatorio de citas
- Tienda de productos de barbería

**Características destacadas:**
- Interfaz moderna con tema oscuro premium
- Notificaciones push en tiempo real
- Soporte para múltiples barberías
- Sistema de roles (dueño, barbero, cliente)
- Lista de espera para horas ocupadas
- Mensajería interna entre equipo
- Actualizaciones automáticas sin reinstalar

BarberFlow simplifica la gestión de tu barbería para que te centres en lo que mejor sabes hacer: cortar pelo.

## Formulario de seguridad de datos
Respuestas para el formulario de Google Play:

1. ¿La app recopila o comparte datos de usuario? → Sí
2. ¿Todos los datos recopilados están cifrados en tránsito? → Sí (Firebase usa HTTPS)
3. ¿Los usuarios pueden solicitar la eliminación de datos? → Sí

### Tipos de datos recopilados:
- **Información personal**: Nombre, email (para crear cuenta)
- **Fotos** (opcional): Solo si el usuario sube foto de perfil o galería
- **Información de la app**: Registro de fallos (Sentry), datos de analítica
- **Identificadores del dispositivo**: Token de notificaciones push

### Propósito de la recopilación:
- Funcionalidad de la app
- Analítica
- Comunicaciones (notificaciones push)

### Compartición de datos:
- No se comparten datos con terceros
- Firebase (Google) procesa los datos como proveedor de infraestructura
